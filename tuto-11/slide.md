## Synthèse de ma veille technologique
- **Définition en une phrase :** La modularité consiste à découper son code en petits morceaux réutilisables (fichiers inclus et fonctions) pour ne jamais l'écrire deux fois : c'est le principe DRY.
- **Problème résolu pour le projet :** Copier-coller le même code (header, footer, calculs) dans plusieurs pages est la première source de bugs : une correction oubliée dans un seul fichier suffit à casser le site. Avec un seul `header.php` inclus partout et des fonctions, on corrige une fois pour toutes les pages.
- **Mes 3 mots-clés :** Inclusion (require_once) — Fonctions réutilisables — Principe DRY
