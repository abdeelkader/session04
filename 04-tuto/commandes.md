
# PHP — Commandes exécutées

## 1. Vérification de la version PHP

```bash
php -v
```

Cette commande permet de vérifier la version de PHP installée.

## 2. Démarrage du serveur local

```bash
php -S localhost:8000
```

Cette commande permet de démarrer le serveur PHP local sur le port 8000.

## 3. Accès au serveur

URL : http://localhost:8000/test-serveur.php
